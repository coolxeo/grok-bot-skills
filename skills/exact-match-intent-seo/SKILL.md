# Exact-match intent SEO (EMD lesson)

Triggered by posts that credit **EMD SEO** (Exact Match Domain) for high CTR on new sites — e.g. [Hridoy Reh](https://x.com/hridoyreh/status/2096534436934455606) showing ~8.9k clicks / 27.3k impressions / **32.7% CTR** / avg position **2.8** after months of near-zero.

## What the claim usually means

An **Exact Match Domain** is a domain whose name equals the target query (e.g. `slow-toddler-songs.com`). Classic SEO used EMDs as a ranking shortcut. In 2026 that boost is weak or gone as a direct factor; what still works is **exact intent match** across:

- Domain *or* path (slug)
- Title tag
- H1
- Opening copy
- SERP snippet (high CTR when query ≈ title)

High CTR + top-3 average position usually means the result looks like the answer to a specific query, not a broad brand homepage.

## Do / don't

**Do (brand sites and new niches)**

1. One primary intent per page. Name it in the slug, H1, and title the same way parents type it.
2. Prefer **exact-match paths** on a brand domain (`/slow-toddler-songs`) over buying a spammy EMD for every keyword.
3. Write titles for CTR: clear, specific, honest. Avoid bait that the page does not pay off.
4. Expect a **sandbox / lag**: months of near-zero impressions, then a sharp climb. Do not kill pages early without a GSC read.
5. After indexation, use Search Console: queries with impressions but weak copy get the phrase into H2 / body / alt (refresh, don’t spam).
6. Keep one indexable page per intent. Do not duplicate the same keyword across many thin URLs.

**Don't**

- Buy a keyword EMD and ship thin affiliate pages. Google still demotes low-quality EMDs.
- Over-repeat the domain keyword in every title and heading (over-optimization).
- Replace a working brand domain with a string of EMDs for the same product.
- Treat a GSC flex video as a full playbook when it only shows metrics + music.

## When an EMD *is* worth considering

Only for a **new niche property** where the whole site is that one intent, content depth is real, and you are not splitting brand authority. Microsite, not the main brand door. Default for an established brand: stay on the brand domain and use exact-match slugs.

## Checklist before shipping an intent page

- [ ] Primary query written in plain words
- [ ] Slug matches that query (kebab-case)
- [ ] Single H1 matches intent (not a clever brand-only line unless brand *is* the query)
- [ ] Title ≈ H1, under ~60 chars when possible, no false claims
- [ ] First paragraph answers who / what / what next
- [ ] Unique from other pages (no near-duplicates)
- [ ] In sitemap if indexable; `noindex` only for experiments
- [ ] After 4–8 weeks: GSC query report → refresh for “impressions, not in copy”
