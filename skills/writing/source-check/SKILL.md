# Source check

Verify every factual claim before publish. Read-only except adding a Sources section.

## Pass 1 — Extract

Line by line, log factual claims, statistics, attributed statements, historical claims, causal assertions. Skip clearly labeled personal opinion.

## Pass 2 — Verify

For each claim, in order: named in the draft, then available files/notes, then a primary web source. Rate: Verified, Unverified, Unsupported, Overstated. Record publication, title, date, URL.

## Pass 3 — Quality

Flag single-source lean, stale stats, cherry-picking, vague attribution (“studies show”, “experts agree”), weak outlets.

## Pass 4 — Sources section

Numbered list grouped by section. Update, do not duplicate.

## Verdict

Solid / Mostly solid / Needs work / Unreliable. Suggest a fix for every problem. Do not rewrite prose.

Original sources only. If a reporter cites a study, cite the study. Personal observation and common knowledge do not need a citation.
