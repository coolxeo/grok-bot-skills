# Skill credits

Updated 2026-10-12. Every skill in this repo is Dani Acosta's own version, written in our own words and inspired by several references instead of copied from one. Each `SKILL.md` ends with an **Inspired by** section (what each reference does well and what it was missing) and a **What this version adds** list. This table summarizes them.

Every "missing" claim below was checked against the linked source on the update date. Rewrites were checked for copied text: no run of 8 or more words in common with any reference we fetched, apart from titles, URLs, and command or field literals.
